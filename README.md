# 🧠 Flashcards

A web app for creating flashcard-based quizzes by topic. Users can:

- Create topics
- Create quizzes within topics
- Add custom flashcards with front/back content
- Flip flashcards to study interactively

Built with React and Redux Toolkit, this was one of my earliest explorations into managing complex app state with Redux — an opportunity to internalize key patterns for scalable front-end architecture.

## 🧰 Tech & Tools

- React
- Redux Toolkit
- React Router
- Modular component architecture

## 🧪 Concepts Practiced

- Redux store setup, reducers, and actions
- Normalized state for multiple entities (topics, quizzes, cards)
- Component-driven design with stateful containers
- Routing and nested data relationships
